B6 - Inicio Forzado (Fuera del Bucle)
Importante: Esto va ANTES del 'while True'. Es lo que permite que el juego arranque solo.
# Forzar el primer mensaje historial.append({"role": "user", "content": "Empezar la partida."}) respuesta = consultar_ia(historial, 0.7) historial.append({"role": "assistant", "content": respuesta}) print(f"\nNarrador: {respuesta}\n") # Ahora sí, arranca el bucle while True: accion = input("¿Qué hacés? > ").strip() if accion.lower() == "salir": break # ... acá van tus IF de comandos manuales ...
B7 - El Turno (Dentro del Bucle)
Este código debe ir al final del bloque 'while', después de todos los 'if' de comandos.
# Si no fue un comando manual, entra la IA mensaje_turno = f"[Estado: {jugador}] Acción: {accion}" historial.append({"role": "user", "content": mensaje_turno}) narracion = consultar_ia(historial, 0.8) historial.append({"role": "assistant", "content": narracion}) print(f"\nNarrador: {narracion}\n")
