1 EL DICT DEL ENEMIGO

Igual que tenés jugador = {...} con el HP de Malena, ahora creás un dict para el enemigo. Va fuera del while True, junto al de Malena.

# Junto a tu jugador = {...} — FUERA del while enemigo = { "nombre": "", "hp": 0, "activo": False }
💡 Por qué la clave "activo" Cuando activo es False, no hay pelea: el programa no muestra la barra de vida del enemigo. Cuando aparece un enemigo, se pone en True. Así podés tener varios enemigos distintos a lo largo del juego.
⚠️ Importante: ¿por qué va FUERA del bucle? Si lo ponés adentro del while True, se reiniciaría en cada turno — el enemigo recuperaría todo su HP en cada vuelta y sería inmortal. Es la misma razón por la que tu variable turno va afuera.

2 AVISARLE A LA IA

La IA tiene que decirte, en su respuesta JSON, cuánto daño recibió el enemigo. Agregá esto a tu system prompt, junto a las instrucciones de las otras claves.

# Agregá a tu system prompt: """ ...tus instrucciones actuales... Sobre combate: - Si Malena se enfrenta a un enemigo, incluí la clave "enemigo": {"nombre": "nombre del enemigo", "hp_cambio": N} donde hp_cambio es el daño que recibió el enemigo este turno (negativo). - Si no hay pelea, "enemigo" debe ser null. """
✍️ Adaptalo a tu mundo En tu Ushuaia post-apocalíptica el enemigo puede ser "saqueador del puerto", "criatura del agua tóxica", "perro salvaje". El nombre lo decide la IA según la historia — vos solo definís la estructura.

3 PROCESAR EL DAÑO AL ENEMIGO

Donde ya procesás el hp_cambio de Malena (en tu bloque del JSON), agregás justo después el procesamiento del enemigo.

# ✍️ Después de procesar el hp_cambio de Malena: datos_enemigo = datos.get("enemigo") if datos_enemigo: # Si es un enemigo nuevo, lo activamos con HP inicial if not enemigo["activo"]: enemigo["nombre"] = datos_enemigo["nombre"] enemigo["hp"] = 60 # ✍️ definí vos el HP inicial enemigo["activo"] = True print(f"⚔️ ¡{enemigo['nombre']} aparece! HP: {enemigo['hp']}") # ✍️ Aplicar el daño enemigo["hp"] += datos_enemigo["hp_cambio"] # ✍️ ¿Cayó? if enemigo["hp"] <= 0: print(f"💀 ¡{enemigo['nombre']} fue derrotado!") enemigo["activo"] = False enemigo["hp"] = 0 else: print(f"⚔️ {enemigo['nombre']} — HP: {enemigo['hp']}")
🐛 Ojo con el TypeError Si no ponés if datos_enemigo: y la clave es null, al intentar datos_enemigo["hp_cambio"] el programa explota con un TypeError. La verificación es obligatoria.

4 MOSTRAR LA BARRA DEL ENEMIGO

Ya mostrás el HP de Malena. Agregá la del enemigo, que solo aparece si activo == True.

# ✍️ Después de mostrar el HP de Malena: if enemigo["activo"]: print(f"⚔️ {enemigo['nombre']}: {enemigo['hp']} HP")
🧪 Cómo probar todo el combate Jugá hasta que aparezca un enemigo (algo como "atacá al saqueador"). Verificá que aparece la barra con su HP. Atacalo varios turnos → el HP baja. Cuando llega a 0 → mensaje de derrota y la barra desaparece. Cuando no hay pelea → no aparece nada.

★ SI TE SOBRA TIEMPO

El enemigo también pega Que la IA devuelva además cuánto daño le hizo el enemigo a Malena en ese turno (dentro del hp_cambio de ella, o una clave nueva). Así el combate es de ida y vuelta: Malena puede morir peleando. Conecta directo con tu condición de fin del juego (HP ≤ 0).
