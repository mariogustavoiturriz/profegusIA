🎯 Meta: Hacer que Python hable con la IA por primera vez

Vas a construir la función que conecta tu código con Groq. Al final de esta sesión, tu programa manda un mensaje y recibe una respuesta.

📦 Paso 1 — Abrí un Colab nuevo y escribí el import
requests es la librería que le permite a Python hablar con servicios externos por internet. La usás para mandar el mensaje a la API de Groq.
import requests
🔑 Paso 2 — Tu API Key y los datos de conexión
Reemplazá "gsk_TU_CLAVE" con tu API Key real de Groq. La URL y los headers siempre son iguales para todos.
API_KEY = "gsk_TU_CLAVE" URL = "https://api.groq.com/openai/v1/chat/completions" headers = { "Authorization": f"Bearer {API_KEY}", "Content-Type": "application/json" }
⚙️ Paso 3 — La función que habla con la IA
Esta función recibe una lista de mensajes, los manda a Groq, y devuelve lo que respondió la IA. El try/except atrapa los errores para que el programa no explote.
def consultar_ia(mensajes, nivel_creatividad): payload = { "model": "llama-3.3-70b-versatile", "temperature": nivel_creatividad, "messages": mensajes } try: respuesta = requests.post(URL, headers=headers, json=payload) return respuesta.json()["choices"][0]["message"]["content"] except Exception as e: return f"Error: {e}"
✅ Paso 4 — Probá que funciona
Copiá este bloque en una celda nueva y ejecutalo. Si recibís una respuesta de la IA, la función está lista.
prueba = [{"role": "user", "content": "Decí exactamente: 'La función funciona'"}] resultado = consultar_ia(prueba, 0.1) print(resultado)
📤 Checkpoint — antes de seguir a la Sesión 2 Tu función tiene que devolver una respuesta de la IA. Si aparece un error, revisá la API Key. Si dice "La función funciona" (o algo parecido), pasás a la Sesión 2.
🧠 Repaso — Sesión 1

🎯 Meta: La IA recuerda la conversación y tiene personalidad

Vas a agregar el historial (para que recuerde) y el system prompt (para darle personalidad). Al final, vas a tener un chatbot con identidad propia.

📋 Paso 1 — El historial es una lista de mensajes
El historial guarda toda la conversación. La IA lo lee completo en cada llamada — así "recuerda" lo que pasó antes. La posición 0 siempre es el system prompt.
# Elegí un tema para tu chatbot system_prompt = """Sos un asistente de recetas amigable y práctico. Solo hablás de cocina. Si te preguntan otra cosa, respondés que tu especialidad es la cocina. Tus respuestas son cortas y claras.""" historial = [{"role": "system", "content": system_prompt}]
🔄 Paso 2 — Un turno de conversación
Para cada mensaje: primero lo agregás al historial, después llamás a la IA, después guardás la respuesta. Este orden es importante.
# 1. Agregar el mensaje del usuario historial.append({"role": "user", "content": "¿Cómo hago una tortilla de papas?"}) # 2. Llamar a la IA respuesta = consultar_ia(historial, 0.7) # 3. Guardar la respuesta de la IA en el historial historial.append({"role": "assistant", "content": respuesta}) # 4. Mostrar la respuesta print(respuesta)
✅ Paso 3 — Probá la memoria
Hacé dos preguntas encadenadas. Si en la segunda respuesta la IA recuerda la primera, el historial funciona.
# Primer mensaje historial.append({"role": "user", "content": "¿Cuántos huevos lleva la tortilla?"}) resp1 = consultar_ia(historial, 0.7) historial.append({"role": "assistant", "content": resp1}) print("IA:", resp1) # Segundo mensaje (prueba de memoria) historial.append({"role": "user", "content": "¿Y si quiero una versión más grande?"}) resp2 = consultar_ia(historial, 0.7) historial.append({"role": "assistant", "content": resp2}) print("IA:", resp2)
📤 Checkpoint — antes de seguir a la Sesión 3 La IA tiene que responder preguntas de cocina (o el tema que elegiste) y en la segunda respuesta tiene que referirse a la primera. Si no lo hace, revisá que estés haciendo el append del assistant después de cada respuesta.
🧠 Repaso — Sesión 2

🎯 Meta: El chatbot corre en un bucle y guarda la conversación

Vas a juntar todo lo anterior en un programa que funciona como un chat real: el usuario escribe, la IA responde, y se puede guardar la conversación.

🔁 Paso 1 — El bucle while True
while True repite para siempre. input() espera que el usuario escriba. .strip() limpia los espacios. break es la única forma de salir.
print("¡Chatbot listo! Escribí 'salir' para terminar.\n") while True: mensaje = input("Vos: ").strip() if mensaje.lower() == "salir": print("Hasta la próxima.") break # Agregar mensaje al historial historial.append({"role": "user", "content": mensaje}) # Llamar a la IA respuesta = consultar_ia(historial, 0.7) # Guardar la respuesta de la IA historial.append({"role": "assistant", "content": respuesta}) # Mostrar la respuesta print(f"IA: {respuesta}\n")
💾 Paso 2 — Guardar la conversación en un archivo
Agregá este bloque antes del break de "salir", o como comando /guardar. historial[1:] saltea el system prompt y guarda solo la conversación.
if mensaje.lower() == "/guardar": with open("conversacion.txt", "w", encoding="utf-8") as f: for msg in historial[1:]: f.write(f"{msg['role'].upper()}: {msg['content']}\n\n") print("💾 Conversación guardada en conversacion.txt\n") continue
