La Regla de Oro: El Restaurante

Para entender tu código, imaginate que tu programa es un restaurante:

  • La Cocina (Backend): Es la función consultar_ia. El chef trabaja a puertas cerradas, se conecta a internet y cocina la respuesta. Nunca sale a hablar con el cliente (no usa print).
  • El Salón (Frontend): Es el bucle while True. Es el mozo que atiende al usuario, anota los pedidos y habla con él.
  • La Libreta (El Historial): Es la memoria. El mozo anota TODO ahí para no olvidarse de nada.
CAJA AZUL: EL MOTOR (No se toca)
Lo que está en estas cajas es estructural. Solo tenés que copiarlo y ubicarlo en el lugar correcto.
CAJA ROJA: TU CREATIVIDAD (Vos programás)
Acá completás vos. Son tus datos, tus reglas y tus variables.

¿Cómo funciona la memoria? (El Historial)

A los chicos de IA les cuesta entender por qué usamos .append() todo el tiempo. La lista historial es, literalmente, un chat de WhatsApp interno. Cada mensaje tiene un "quién" (role) y un "qué dijo" (content).

CÓMO SE VE LA LIBRETA POR DENTRO
A medida que avanza el programa, la lista va creciendo así:
Posición 0 (System){"role": "system", "content": "Sos Batman"}
Posición 1 (User){"role": "user", "content": "Hola, ¿quién sos?"}
Posición 2 (Assistant){"role": "assistant", "content": "Soy la venganza."}
Posición 3 (User){"role": "user", "content": "¿Te gustan los gatos?"}
¡Si no guardamos el mensaje del usuario y la respuesta de la IA en cada vuelta, el bot se olvida de lo que acabamos de hablar!

PARTE 2: El Motor (Adentro del while True)

El bucle while True es un ciclo infinito. En cada vuelta, el programa se frena en el input() a esperar que el usuario escriba. Dependiendo de lo que escriba, toma uno de tres caminos (los IFs):

Las 3 Puertas del Frontend
while True: consulta = input("Vos: ") # EL PROGRAMA SE FRENA ACA # --------------------------------------------------------- # PUERTA 1: EL USUARIO SE QUIERE IR # Si escribe salir, nos despedimos y rompemos el ciclo (break). if consulta.lower() == "salir": print("¡Chau!") break # --------------------------------------------------------- # PUERTA 2: EL USUARIO QUIERE GUARDAR EL LOG # Escribimos el .txt en el disco y volvemos a empezar (continue). if consulta.lower() == "/guardar": with open("conversacion.txt", "w", encoding="utf-8") as archivo: for linea in historial: archivo.write(f"{linea['role']}: {linea['content']}\n\n") print("¡Archivo guardado con exito!") continue # Ignora lo de abajo y vuelve a pedir un input # --------------------------------------------------------- # PUERTA 3: EL USUARIO QUIERE CHARLAR (El camino normal) # Si no escribio "salir" ni "/guardar", entonces le esta hablando a la IA. # A) Anotamos lo que dijo el usuario en la libreta historial.append({"role": "user", "content": consulta}) # B) Le mandamos la libreta al Backend (Chef) para que cocine la respuesta respuesta_ia = consultar_ia(historial, temp) # C) Imprimimos la respuesta en pantalla (El Mozo sirve el plato) print(f"IA: {respuesta_ia}") # D) Anotamos lo que respondio la IA en la libreta para que no se olvide historial.append({"role": "assistant", "content": respuesta_ia})
