1 ACTUALIZAR EL SYSTEM PROMPT

El JSON que devuelve la IA tiene que incluir una clave nueva: enemigo. Agregá esto al final de tu system prompt, junto a las instrucciones de las otras claves.

💡 Lo que tiene que decir el system prompt La instrucción tiene que aclarar: cuándo incluir la clave, qué estructura tiene, y qué significa cada valor. El hp_cambio del enemigo es negativo cuando recibe daño.
# Agregá esto a tu system prompt (dentro de las instrucciones JSON): """ ...tus instrucciones actuales... Sobre el enemigo: - Cuando haya un enemigo activo en combate, incluí la clave "enemigo": {"nombre": "nombre del enemigo", "hp_cambio": N} donde hp_cambio es el daño que recibió el enemigo en este turno. Si el jugador no atacó o no hay enemigo, "enemigo" debe ser null. """
✍️ Tu trabajo Adaptá el texto al tono y mundo de tu juego. "Guardia noxiano" en Runaterra suena diferente a "bestia mutante" en otro juego. La instrucción funciona igual — el nombre del enemigo lo decide la IA según la narrativa.

2 NUEVO DICT EN EL B4

Junto al dict jugador, agregá el dict del enemigo. Empieza vacío — la IA lo activa cuando el combate empieza.

# B4 — junto a tu jugador = {...} enemigo_activo = { "nombre": "", "hp": 0, "activo": False }
💡 Por qué la clave "activo" Cuando activo es False, el programa sabe que no hay enemigo en combate y no muestra la barra de vida del enemigo. Cuando la IA introduce un enemigo, el código lo activa y le asigna HP. Esto permite tener múltiples enemigos a lo largo del juego.

3 PROCESAR EL ENEMIGO EN EL BUCLE

Después del bloque donde ya procesás hp_cambio del jugador, agregá el procesamiento del enemigo. Va en el mismo bloque try/except del JSON.

💡 Lógica del procesamiento · Si datos["enemigo"] no es null → hay un enemigo en este turno.
· Si el enemigo no estaba activo → es uno nuevo, asignale HP inicial (podés pedirle a la IA que incluya hp_inicial también).
· Sumá el hp_cambio al HP del enemigo.
· Si el HP llegó a 0 o menos → el enemigo cae, marcá activo = False.
# ✍️ Después de procesar datos["hp_cambio"] del jugador: datos_enemigo = datos.get("enemigo") if datos_enemigo: # Si es un enemigo nuevo, inicializarlo if not enemigo_activo["activo"]: enemigo_activo["nombre"] = datos_enemigo["nombre"] enemigo_activo["hp"] = 80 # ✍️ definí vos el HP inicial del enemigo enemigo_activo["activo"] = True print(f"⚔️ ¡Nuevo enemigo! {enemigo_activo['nombre']} — HP: {enemigo_activo['hp']}") # ✍️ Aplicar el daño recibido por el enemigo enemigo_activo["hp"] += datos_enemigo["hp_cambio"] # ✍️ Verificar si el enemigo cayó if enemigo_activo["hp"] <= 0: print(f"💀 ¡{enemigo_activo['nombre']} fue derrotado!") enemigo_activo["activo"] = False enemigo_activo["hp"] = 0 else: print(f"⚔️ {enemigo_activo['nombre']} — HP restante: {enemigo_activo['hp']}")
