📌 UN SOLO CONCEPTO NUEVO

display(HTML("...")) muestra HTML con colores y estilos en la celda de Colab — como si fuera una página web. Solo necesitás este import al principio del programa:

from IPython.display import display, HTML

La diferencia entre print() y display(HTML()):

print — texto plano
print("HP: 65")
display(HTML) — con color
display(HTML("<b style='color:orange'>HP: 65</b>"))
¿Y el HTML? ¿Necesito saber mucho? Solo tres cosas: style="background:color" para el fondo, style="color:color" para el texto, y style="padding:10px" para el espacio interno. Con eso alcanza para todo lo que vamos a hacer.

📖 EL HTML QUE VAMOS A USAR — PASO A PASO

El HTML dentro de las f-strings tiene solo 5 piezas. Ninguna es complicada. Acá las explicamos de a una.

1. <div> — una caja Un <div> es simplemente una caja. Todo lo que ponés adentro queda agrupado. Con el atributo style le das color, forma y tamaño. Probalo con cualquier texto.
# Probalo — cambiá "Hola mundo" por lo que quieras display(HTML("<div> Hola mundo </div>"))
2. background — color de fondo Pinta el fondo de la caja. El color va en inglés (black, green, navy) o en código hex (#FF0000 = rojo). Buscá "color picker hex" en Google para elegir el tuyo.
# Cambiá EL_COLOR por un color en inglés o código hex display(HTML("<div style='background:EL_COLOR'> Hola mundo </div>")) # ↑ style='...' va DENTRO de la etiqueta, separado con dos puntos del valor
3. color — color del texto Cambia el color de las letras. Si el fondo es oscuro, el texto tiene que ser claro — si no, no se lee.
# Cambiá FONDO y COLOR_TEXTO por los colores que elijas display(HTML("<div style='background:FONDO; color:COLOR_TEXTO'> Hola mundo </div>")) # ↑ dos propiedades → las separás con punto y coma ;
4. padding — espacio interno El espacio entre el borde de la caja y el texto. Sin padding el texto queda pegado al borde. Se mide en píxeles (px). Probá con 8px, 12px, 20px y fijate la diferencia.
# Cambiá N por el número de píxeles que quieras display(HTML("<div style='background:FONDO; color:COLOR_TEXTO; padding:Npx'> Hola mundo </div>"))
5. border-radius — bordes redondeados Redondea las esquinas. Con 4px casi no se nota. Con 12px se nota bastante. Con 50% se convierte en círculo. Probá distintos valores.
# Cambiá N por el redondeo que te guste display(HTML("<div style='background:FONDO; color:COLOR_TEXTO; padding:Npx; border-radius:Npx'> Hola mundo </div>"))
6. border-left — línea del lado izquierdo Dibuja una línea de color en el borde izquierdo. El formato es siempre: GROSOR solid COLOR. El grosor típico es 4px. El color lo elegís vos.
# Cambiá COLOR_LINEA por el color que quieras para la línea display(HTML("<div style='background:FONDO; color:COLOR_TEXTO; padding:Npx; border-radius:Npx; border-left:4px solid COLOR_LINEA'> Hola mundo </div>")) # ↑ con esas 5 propiedades ya tenés el estilo completo de una burbuja
7. width:% — ancho en porcentaje (solo para la barra de HP) Con width:65% la caja ocupa el 65% del espacio disponible. La barra de HP usa dos div anidados: el de afuera es el fondo gris (siempre 100%), el de adentro es el color que cambia según el HP.
# Cambiá COLOR_VIDA y el porcentaje por los que correspondan display(HTML(""" <div style='background:FONDO_BARRA; border-radius:Npx; height:20px;'> <div style='background:COLOR_VIDA; width:PORCENTAJE%; height:20px; border-radius:Npx;'> </div> </div> """)) # ↑ div de afuera: el fondo gris que ocupa todo el ancho # ↑ div de adentro: el color de vida, ocupa solo el % que corresponde al HP
✅ Eso es todo el HTML que necesitás background, color, padding, border-radius, border-left, width. Con esas 6 propiedades armás la barra de HP, las burbujas y el inventario.
