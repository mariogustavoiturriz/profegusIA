3 LOS GRUPOS Y LOS NIVELES

Grupos de 2

🗺️ Estado + Comandos manuales

La IA devuelve solo la narración. El jugador debe actualizar el estado con comandos (ampliando lo que hicimos en el TP2).

  • Diccionario con HP, inventario, ubicación.
  • Usan comandos manuales: /estado, /tomar, /hp, etc.
  • Pueden crear nuevos comandos usando if accion.startswith("..."):
Grupos de 3

🧠 Desafío de Prompting: Formato Estricto (JSON)

En lugar de usar expresiones regulares complejas, el desafío es obligar a la IA a devolver ÚNICAMENTE un formato de datos (JSON) usando instrucciones muy estrictas en el Prompt.

  • Sin usar comandos manuales de /tomar o /hp.
  • El código lee el JSON con json.loads() y actualiza el diccionario automáticamente.
  • El reto: Si la IA responde con texto normal ("¡Claro! Acá tenés la respuesta..."), el programa fallará. ¡Deben domar al modelo con reglas inquebrantables!
