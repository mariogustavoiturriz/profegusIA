2 ANTES DE EMPEZAR — ERRORES DEL TP2

Repasemos los errores más comunes que hay que corregir antes del recuperatorio:

🔥 Fuga de tokens

El /guardar va antes de llamar a la IA. Si va al final, el historial completo ya se mandó a la API antes de cerrar.

👻 Variables que no se usan

Si declarás una variable con input() pero nunca la usás en el código, sobra. Borrala o incorporala donde corresponde.

⟹ Sangrías (indent)

Python es estricto. Una tabulación fuera de lugar dentro del while rompe el programa o produce comportamiento incorrecto.

🔁 B7 — El bucle y los comandos ← NUEVO
El while True es el mismo del TP2. Lo nuevo son los comandos que actualizan el diccionario jugador manualmente.

¿Por qué continue después de cada comando? Para que el código no siga ejecutando las líneas de abajo (que llaman a la IA). Sin continue, el comando /estado también le preguntaría a la IA — gastando tokens innecesarios.

¿Qué hace ", ".join(jugador["inventario"])? Une los elementos de la lista en un texto: ["espada", "antorcha"] → "espada, antorcha".
🔥 TU DESAFÍO: PROGRAMAR LOS COMANDOS /estado Y /hp En el código de abajo vas a notar que dejamos dos bloques comentados para que los resuelvas vos. Usando tus conocimientos sobre diccionarios, tenés que lograr lo siguiente:
  • Comando /estado: Detectá si el usuario escribió "/estado". Si es así, usá print() para mostrar en pantalla los puntos de vida (jugador["hp"]) y los objetos de la mochila (jugador["inventario"]). Recordá poner el continue al final.
  • Comando /hp: Atrapá el número que el usuario escribe después de "/hp " (por ejemplo, "-20"). Ese número tenés que sumarlo o restarlo al valor actual de jugador["hp"]. ¡Fijate cómo el comando /tomar recorta el texto para saber qué agarrar!
# B7: El bucle principal while True: accion = input("Acción > ").strip() if accion.lower() == "salir": print("Fin de la aventura.") break # /guardar va ANTES de llamar a la IA para no gastar tokens innecesarios if accion.lower() == "/guardar": with open("log_partida.txt", "w", encoding="utf-8") as f: f.write(f"ESTADO: {jugador}\n\n") for msg in historial[1:]: # historial[0] es el system prompt, lo salteamos f.write(f"{msg['role'].upper()}: {msg['content']}\n\n") print("💾 log_partida.txt generado.\n") continue # vuelve arriba sin llamar a la IA # ── TU DESAFÍO: agregá el comando /estado ───────────────────────────── # Cuando el jugador escriba "/estado", queremos mostrar la ficha: # ❤️ Vida: 80 | 🎒 llave, antorcha # # Tips: # 1. Detectá si accion == "/estado" (igual que /guardar) # 2. Usá jugador["hp"] para la vida y jugador["inventario"] para los objetos # 3.
