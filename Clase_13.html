1 EL PROYECTO: UNA AVENTURA CONVERSACIONAL

Hoy empezamos el desarrollo del Proyecto 2 (Aventura RPG). Dejamos atrás al bot estático del TP2 y nos introducimos en la creación de un Juego de Rol interactivo, donde la IA actúa como el Director de Juego (Game Master) guiando la historia.

La IA ya no responderá de forma pasiva. Ahora tomará el control: describirá el escenario, reaccionará a lo que decidas y te presentará 3 opciones lógicas para continuar. El reto principal de hoy es escribir instrucciones tan rigurosas en su prompt que el narrador nunca tome decisiones por el jugador.

2 ANTES DE EMPEZAR: CUIDADO CON ESTOS ERRORES

Para evitar fallas de código y optimizar el rendimiento de la API de Groq, repasemos los descuidos más comunes vistos en el TP2:

🔥 Fuga de tokens (/guardar)

El comando /guardar debe ir antes de consultar a la IA. No queremos enviar el historial completo a la nube una vez que el bucle ya terminó.

👻 Variables fantasma

Si pedís datos de entrada (como el nombre del guerrero o un objeto inicial), tenés que inyectarlos en tu System Prompt. Declararlas sin llamarlas ensucia el código.

⟹ Indentación (Sangrías)

Python es muy estricto. Una tabulación fuera de lugar adentro del bucle while causará errores lógicos o detendrá el script por completo.

# --- Bloque 3: Función de conexión a la IA --- def consultar_ia(mensajes, temperatura): payload = {"model": "llama-3.3-70b-versatile", "temperature": temperatura, "messages": mensajes} try: respuesta = requests.post(URL, headers=headers, json=payload) return respuesta.json()["choices"][0]["message"]["content"] except Exception as e: return f"Error de conexión: {e}"

🎭 B5 — System Prompt (Instrucciones)
Definí las directrices estrictas para que la IA actúe como un narrador impecable.
# --- Bloque 5: El Cerebro del Juego (System Prompt) --- game_master = """ Sos el Narrador de un juego de rol de supervivencia ambientado en [MUNDO]. Tu tono de escritura debe ser [MISTERIOSO/ÉPICO] y muy atrapante. REGLAS INQUEBRANTABLES: 1. Describí qué pasa en el entorno usando máximo 2 o 3 oraciones. Sé directo. 2. NUNCA tomes decisiones por el jugador. No asumas que corrió, saltó o atacó. 3. Al final de tu descripción, SIEMPRE dale al jugador 3 opciones claras (A, B, C). 4. Pedile al jugador explícitamente: "¿Qué vas a hacer? Elegí A, B o C". """ historial = [{"role": "system", "content": game_master}]
🔁 B6 — Bucle de Entrada (While)
Como hoy no tenemos "Automatización", el jugador usará comandos como /hp o /tomar para actualizar su estado.
# --- Bloque 6: Bucle Principal --- print("🎮 TU JUEGO RPG") print("Comandos ocultos: /estado /tomar objeto /hp -20 /guardar /salir\n") while True: accion = input("Acción > ").strip() if accion.lower() == "salir": break if accion.lower() == "/guardar": # Esto solo guarda un LOG de texto para que el profe corrija. No retoma partidas. with open("log_partida.txt", "w", encoding="utf-8") as f: f.write(f"ESTADO: {jugador}\n\n") for msg in historial[1:]: f.write(f"{msg['role'].upper()}: {msg['content']}\n\n") print("💾 Archivo log_partida.txt generado.\n") continue if accion.lower() == "/estado": inv = ", ".join(jugador["inventario"]) or "Mochila vacía" print(f"\n❤️ Vida: {jugador['hp']} | 🎒 {inv}\n") continue if accion.lower().startswith("/tomar "): jugador["inventario"].append(accion[7:].strip()); print("🎒 Agregado\n"); continue if accion.lower().startswith("/hp "): try: jugador["hp"]=max(0, jugador["hp"]+int(accion[4:])); print(f"❤️ HP: {jugador['hp']}\n") except: print("Usá: /hp -20 o /hp +10\n") continue
💬 B7 — Inyección de Estado y Turno
Le enviamos los datos del jugador a la IA de manera oculta antes de la narración. Va adentro de la indentación del while.
# --- Bloque 7: El Turno --- # Inyectamos el estado oculto del jugador para que el Narrador sepa cómo venimos mensaje_turno = f"""[Jugador: {jugador['nombre']} | Vida: {jugador['hp']} | Mochila: {jugador['inventario']}] Acción del jugador: {accion}""" historial.append({"role": "user", "content": mensaje_turno}) print("...") respuesta_ia = consultar_ia(historial, 0.7) # Temperatura creativa historial.append({"role": "assistant", "content": respuesta_ia}) print(f"\n🌲 {respuesta_ia}\n")
