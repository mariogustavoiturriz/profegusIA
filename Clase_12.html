0 EL PROBLEMA DE LA MEMORIA RAM

Las últimas clases construimos chatbots con memoria y personalidad. Pero hay un problema silencioso: toda la conversación vive en la RAM — la memoria volátil de Python. En el momento en que escribís "salir" o cerrás Colab, la charla se borra para siempre.

Si este fuera un chatbot de soporte técnico de una empresa, o un asistente educativo que registra el progreso de un estudiante, eso sería un desastre. Necesitamos poder exportar esa conversación a un archivo real que quede guardado en el disco.

La diferencia entre RAM y disco La RAM (memoria volátil) guarda datos mientras el programa corre — si se apaga, se borra. El disco (almacenamiento persistente) guarda datos aunque se apague la máquina. Hoy vamos a mover el historial de la RAM al disco, creando un archivo .txt.

1 MANEJO DE ARCHIVOS EN PYTHON

Para escribir en un archivo guardado en disco, Python tiene la función open(). Se usa siempre con with, que garantiza que el archivo se cierre y guarde correctamente al terminar.

with open("mi_archivo.txt", "w", encoding="utf-8") as archivo: archivo.write("Hola, esto queda guardado en disco.\n") archivo.write("Esta es la segunda línea.\n")

Los tres modos de apertura más comunes

ModoLetraQué hace
Write"w"Crea el archivo si no existe. Si ya existe, lo sobreescribe completamente.
Append"a"Crea el archivo si no existe. Si ya existe, agrega al final sin borrar lo anterior.
Read"r"Abre el archivo en modo lectura. Falla si el archivo no existe.
¿Por qué encoding="utf-8"? El parámetro encoding="utf-8" le dice a Python que el archivo puede tener tildes, ñ y otros caracteres del español. Sin esto, caracteres como "á" o "ñ" pueden aparecer como símbolos raros o causar un error en Windows.
¿Qué hace el \n? Es el carácter de "nueva línea" — equivale a presionar Enter. Si no lo ponemos al final de cada write(), todo el texto queda pegado en una sola línea en el archivo.

3 EL ÚNICO BLOQUE NUEVO — /guardar

Todo lo del esqueleto ya lo escribiste antes. Este es el único código verdaderamente nuevo hoy. Va dentro del while True, después de la condición de salida y antes de agregar el mensaje al historial.

if mensaje.lower() == "/guardar": print("💾 Generando archivo de respaldo...") with open("conversacion.txt", "w", encoding="utf-8") as archivo: for linea in historial: rol = linea["role"].upper() texto = linea["content"] archivo.write(f"{rol}: {texto}\n\n") print("✅ ¡Listo! La charla se guardó en 'conversacion.txt'") continue
for linea in historial Recorre cada diccionario de la lista historial. Cada uno tiene las claves "role" y "content" — las extraemos y las escribimos en el archivo con un salto de línea doble entre cada mensaje.
¿Por qué continue y no break? break cerraría el programa. continue vuelve al inicio del while True — el usuario puede seguir chateando después de guardar.
¿Por qué "w" y no "a"? Con "w" cada /guardar sobreescribe el archivo con la conversación completa hasta ese momento — siempre la versión más actualizada. Con "a" las conversaciones se irían acumulando en el mismo archivo.
